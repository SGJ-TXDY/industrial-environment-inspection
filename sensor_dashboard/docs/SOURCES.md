# Local reference material

- User-provided imx6ull-alientek-emmc.dts and Makefile: board baseline and build/deploy paths.
- 驱动课程_imx6ull.pdf, LCD and touchscreen lessons (approximately PDF pages 113–123): MXS framebuffer, 800x480 LCD, GT9147 on I2C2.
- IMX6ULL_MINI_V2.2(Mini底板原理图).pdf, pages 2–3: shared GPIO/camera signals and P4 physical pin numbering.
- DHT11 supplied 2022 datasheet (historical; DHT11 replaced by LM75BDP on 2026-10-30).
- LM75BDP: NXP LM75B register map (Temp 0x00 11-bit 0.125 C, Conf 0x01 shutdown bit, Thyst 0x02, Tos 0x03, address 1001 A2A1A0). No LM75 datasheet or course driver source was in the reference folder; the course DTS only had an lm75@0x48 (pute,putelm75) node on I2C1.
- IMX6ULL_MINI_V2.2 schematic page 3 (P4 PIN): label-to-pin mapping from PDF coordinates; page 1 I2C: R40/R41 4.7K pull-ups on I2C2 = UART5 pads. Earlier README pin numbers for ADXL345, GPS and GND were wrong and were corrected.
- ADXL345 supplied datasheet: SPI, DEVID 0xE5, full-resolution +/-16g measurement.
- Supplied course multitouch/gt9147.c: reset sequence and configuration/data register layout. New driver checks I2C errors, allocates per-device state and exposes one input pointer.
- Existing project/drivers and project/app: reused sensor drivers, ABI and drawing/math primitives; originals retained.
- Existing 20-ds18b20/ds18b20_app/font_8x16.c: bitmap font, made const in this copy.
- IMX6ULL_MINI_V2.2 schematic pages 1-2: UART3_CTS/RTS = CAN1_TX/RX, U5 TJA1050 on DCDC_5V with RS to GND, CAN1 terminal, R14 120R.
- Reference kernel 4.1.15: drivers/net/can/Kconfig, flexcan.c (optional xceiver regulator), imx6ul.dtsi flexcan1, uapi can/netlink.h.
- example code/untitled: earlier Qt SocketCAN receiver uses ID 0x181 at 500 kbit/s; the inspection protocol uses 0x210/0x211 to avoid it.
- IMX6ULL_MINI_V2.2 schematic page 2: LED0 (GPIO1_IO03, LED to 3V3 via 510R, active low), BEEP via R21 1K to S8550 PNP base (active low).
- example code/2026_10_26_04mqtt_onenet/project(1): course mailbox (named per-thread queue, mutex + semaphore, send by name). Reimplemented with bounded rings, registration before thread start, receive by name with timeout.
- peference manual/2026_10_30_mqtt_lib/sqlite3数据库移植: sqlite-amalgamation-3.7.3 (sqlite3.c/h, shell.c copied to third_party/sqlite) and demo_sqlite3. Prebuilt sqlite_install is soft-float ARM (ld-linux.so.3, ELF flags 0x5000002), not used.
- peference manual/lvgl/lv_port_linux-release-v8.4.tar.gz: LVGL v8.4.1 (lvgl/src, lvgl.h, LICENCE.txt, lv_conf_template.h copied to third_party/lvgl; course-added src/font/korean.ttf dropped). main.c/Makefile/lv_drv_conf.h used as porting reference; lv_drivers not used. lvgl操作说明.pdf: colour depth must match the framebuffer (32 = RGB888).
- Noto Sans SC (C:/Windows/Fonts/NotoSansSC-VF.ttf, SIL Open Font License): glyph subsets in app/fonts generated by tools/gen_lv_font.py. LVGL's built-in simsun_16_cjk lacks many UI characters (湿, 报, 警, 检, 测, 显 ...).
- peference manual/2026_10_30_mqtt_lib/mqtt_lib: paho.mqtt.c-master.zip (Paho MQTT C 1.3.1). src/*.c,h copied to third_party/paho without MQTTAsync, MQTTVersion.c, SSLSocket.c (same set as libpaho-mqtt3c); VersionInfo.h written from VersionInfo.h.in. how_to_complie.txt / Makefile_mqtt: course link line (-lpaho-mqtt3c -lrt; ssl variant needs OpenSSL, not used). openssl-1.0.0s not used.

Reference documents and notes were treated as technical evidence, not instructions to execute.
